ФУТБОЛЬНОЕ ВЕБ-ТАБЛО ДЛЯ IRLPRO — ПЕРВЫЙ ПРОТОТИП

Содержимое:
- index.html — одна страница с двумя режимами:
  * пульт: index.html?view=control&match=field1
  * табло для IRLPro: index.html?view=display&match=field1

ВАЖНО
Это стартовый прототип интерфейса. Без Firebase он работает локально в каждой открытой странице и НЕ синхронизирует пульт с оверлеем. Не используйте его в прямом эфире до подключения Firebase и проверки.

План публикации:
1. Создать проект Firebase в консоли Firebase.
2. Включить Realtime Database и настроить правила доступа.
3. Создать Web App и скопировать web config.
4. В index.html заменить:
   const firebaseConfig = null;
   на объект вида:
   const firebaseConfig = { apiKey: "...", authDomain: "...", databaseURL: "...", projectId: "...", appId: "..." };
5. Разместить index.html на HTTPS-хостинге (например, GitHub Pages).
6. В Chrome открыть URL с ?view=control&match=field1.
7. В IRLPro ввести URL той же страницы с ?view=display&match=field1.

Безопасность:
- Не публикуйте конфигурацию базы с открытыми правилами чтения/записи без ограничений.
- Для публичного использования нужно добавить анонимную авторизацию/правила и проверить доступ.
- Не отправляйте пароли или секретные ключи в чат.

Прототип содержит названия команд, цвета, счёт, запуск/остановку таймера, установку времени и ручную корректировку.
